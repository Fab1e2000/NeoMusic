# NeoMusic 重写需求与前端规格

> 仅用于独立重写任务；现版维护以 [项目规范](../AGENTS.md) 和 [当前进度](roadmap.md) 为准。

版本：1.0 审阅稿 · 日期：2026-11-11 · 状态：需求选择已确认，完整文本待用户审阅。

本文件规定重写版的产品范围、页面表现、动画、业务结果和验收方法。首版面向个人日常使用。重写版采用独立工程和应用身份，与现版并存；现版继续作为视觉与交互参照。

**前端和动画严格对齐现有 NeoMusic。** 本文明确列出的范围调整和行为修正优先；其余页面按下述可见规格实现。源码索引用于追溯数值和行为来源，播放器框架、动画算法和内部架构由实现阶段依据 Apple 官方能力确定。

## 2. 逐页前端规格

以下页面规格包含入口、控件和可见状态。页面内容随账号、歌曲和封面变化，布局及交互按所列条件保持一致。新增云端失败状态使用既有原生提示形式；其效果需按 GAP-08 原生预览确认后接入。

以下尺寸单位为 pt，颜色为 sRGB；数字均从正式源码提取，本轮未新增屏幕量测。系统字体保留其文字样式名称，如正文（body）、说明（footnote）、二级标题（title2）；带有缩放声明的数字为默认字号基值。“主文本色”指系统 primary 文本色，随明暗外观变化；“主题色”指当前强调色。“次级／三级／四级”保留对应系统语义色。系统导航栏、菜单、键盘、分享面板的最终几何以相同系统版本与字号的原生呈现为准，不给出虚构的固定高度或转场时长。页面业务范围按本次确认调整；其余可见结构按下列条目固定。
