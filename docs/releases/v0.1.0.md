# NeoMusic v0.1.0

首个公开开发快照，面向 iOS 27+、iPhone。网易云音乐接入筹备中，当前支持本地音乐。

- 本地歌曲、专辑与艺人资料库，喜爱、置顶及播放列表管理。
- 迷你与全屏播放器、播放队列、本地歌词及播放进度恢复。
- F6 黑色图标，支持深色与系统着色外观。

附件为未签名 IPA，需要自行签名后安装；不包含个人账户素材、开发证书或音乐文件。

这是开发中的版本，包含私有封面取色实验，尚未完成完整系统媒体与发布体验验收。已知限制见 [roadmap](https://github.com/Fab1e2000/NeoMusic/blob/main/docs/roadmap.md)。
