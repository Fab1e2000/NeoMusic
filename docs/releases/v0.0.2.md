# NeoMusic v0.0.2

面向 iOS 27 或更高版本 iPhone 的早期公开构建。

- 优化全屏播放器、播放队列、歌词和播放控制的交互与视觉效果。
- 改进封面加载、资料库搜索、下载进度与播放器流畅度，支持从继续播放列表左滑删除歌曲。
- 修复歌词时间偏移、播放进度及多处界面显示问题。
- 本地音乐可独立使用；网易云账户、歌单、搜索、下载和在线播放已接入，仍在体验验收中。

附件 `NeoMusic-v0.0.2-unsigned.ipa` 未签名。下载后请核对 `SHA256SUMS.txt`，再使用 SideStore、AltStore、Sideloadly 等工具及自己的签名凭据安装。

这是早期版本，没有 App Store 或 TestFlight 构建。当前进度与已知限制见 [路线图](https://github.com/Fab1e2000/NeoMusic/blob/v0.0.2/docs/roadmap.md)。
