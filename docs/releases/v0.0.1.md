# NeoMusic v0.0.1

首个可供自行签名安装的公开构建，面向 iOS 27 或更高版本的 iPhone。

- 本地音乐可独立使用，包括资料库、喜爱、播放列表、专辑、艺人与本地播放。
- 网易云账户、歌单、搜索、下载与在线播放已经接入，仍在体验验收中。
- 包含首页、播放器、播放队列与歌词。

附件 `NeoMusic-v0.0.1-unsigned.ipa` 未签名，不含开发证书、描述文件、已登录账户或音乐文件。下载后请核对 `SHA256SUMS.txt`，再用自己的 Apple ID 或开发者证书，通过 SideStore、AltStore、Sideloadly 等工具签名安装。

这是早期版本，没有 App Store 或 TestFlight 构建。已知限制见 [roadmap](https://github.com/Fab1e2000/NeoMusic/blob/v0.0.1/docs/roadmap.md)。
